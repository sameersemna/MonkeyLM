- Refactored `A11yChecker._sanitize_for_logging` to delegate to `sanitize_for_storage()`
- `BrowserAnomalySensor._on_page_error`: sanitizes error messages and page URLs before storage
- `BrowserAnomalySensor._on_console`: sanitizes console text (promise rejections, CSP violations, console errors) and all stored URLs
- `BrowserAnomalySensor._on_response`: sanitizes request URLs, HTTP methods, and resource types
- `Fuzzer.next_payload`: wraps faker outputs with `str()` to ensure type safety; caps payload length to 1024
- `A11yChecker._reinject_via_evaluate`: bounds axe-core file reads to 10 MiB to prevent memory exhaustion
- `ValidationProber.probe_field`: adds runtime type validation for all parameters (`step`, `action_desc`, `target_id`, `control_type`); guards against empty payload lists
- `run_worker._console_listener`: sanitizes console message text and page URL
- Reflected XSS detection: uses `raw_probe` for SQLi pattern matching against DOM (preserves original text), stores sanitized `payload_probe`; flags on `<` patterns instead of raw `<`
